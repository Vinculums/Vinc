# Functional Analysis ↔ Quantum Mechanics

## One-line essence
The first deep link, formally proved in von Neumann's 1932 *Mathematische Grundlagen*, that a *self-adjoint operator on a Hilbert space* is *exactly the same thing* as a *quantum observable*.

## Mathematics side

Core tools of Analysis §Acts 2·3·4:
- **Hilbert space** $\mathcal{H}$: a complete inner product space
- **Self-adjoint operator** $A^* = A$
- **Spectral theorem**: self-adjoint $A$ = $\int \lambda\, dE_\lambda$ (spectral measure)
- **C\*-algebra / von Neumann algebra**: a closed algebra of bounded self-adjoint operators
- **Tomita-Takesaki theory** (1970): modular automorphism

Tools of infinity categories §Acts 2·3:
- **∞-categorical representation**: a quantum state as a sheaf over an ∞-topos

## Physics side

Core structures of Quantum Mechanics·Quantum Mechanics II:
- **Quantum state** $|\psi\rangle$: a unit vector
- **Observable** $\hat{O}$: a self-adjoint operator
- **Measurement outcome**: the eigenvalues of $\hat{O}$ (spectral measure)
- **Probability**: $|\langle \phi | \psi \rangle|^2$ (Born rule)
- **Time evolution**: $i\hbar\, \partial_t |\psi\rangle = \hat{H} |\psi\rangle$ (Schrödinger)
- **CCR**: $[\hat{x}, \hat{p}] = i\hbar$

Operator algebra in Quantum Gravity — Type III and modular flow §Acts 2~4:
- **Type III von Neumann algebra**: QFT·BH·CPW 2022
- **Modular flow** = local Lorentz boost (Bisognano-Wichmann 1976)

## Exact equivalences·dictionary

| Mathematics | ⟺ | Physics |
|---|---|---|
| Hilbert space $\mathcal{H}$ | ⟺ | quantum state space |
| unit vector $|\psi\rangle \in \mathcal{H}$, $\|\psi\| = 1$ | ⟺ | (pure) quantum state |
| projection operator $P$ | ⟺ | quantum event (yes/no measurement) |
| self-adjoint operator $A^* = A$ | ⟺ | observable |
| spectral measure $dE_\lambda$ | ⟺ | probability distribution of measurement outcomes |
| unitary operator $U^*U = I$ | ⟺ | reversible time evolution |
| Schrödinger equation (∂_t) | ⟺ | one-parameter unitary group generated by $-i\hat{H}$ (Stone's theorem) |
| bounded operator algebra $\mathcal{B}(\mathcal{H})$ | ⟺ | the set of all observables |
| C\*-algebra (Gelfand-Naimark) | ⟺ | abstract quantum system |
| Type I von Neumann factor | ⟺ | finite-degree-of-freedom QM |
| Type II_1 factor | ⟺ | non-commutative probability·random matrix |
| Type III factor | ⟺ | QFT·BH·CPW boundary algebra |
| Tomita-Takesaki modular flow $\sigma_t$ | ⟺ | local Lorentz boost (Bisognano-Wichmann 1976) |
| tensor product $\mathcal{H}_A \otimes \mathcal{H}_B$ | ⟺ | composite system |
| partial trace $\text{Tr}_B$ | ⟺ | reduced density matrix (entanglement) |
| entropy $-\text{Tr}(\rho \log \rho)$ | ⟺ | von Neumann entropy (entanglement entropy) |

**Key theorems**:
- **Stone's theorem** (1932): a one-parameter strongly continuous unitary group = $e^{-itA}$ for some self-adjoint $A$
- **Spectral theorem** (von Neumann 1929): self-adjoint $A$ = $\int \lambda\, dE_\lambda$ exactly
- **Gelfand-Naimark** (1943): a commutative C\*-algebra = $C(X)$ (compact Hausdorff $X$)
- **GNS construction**: state + C\*-algebra → Hilbert space representation
- **Bisognano-Wichmann 1976**: Rindler wedge modular flow = boost generator
- **CPW 2022**: black hole interior + von Neumann Type II_1 entropy well-defined

## Open-problem matrix (the linkage domain itself)

Open problems of this linkage domain — *neither mathematics nor physics can answer them alone*:

1. **The measurement problem (wave function collapse)** — is the Born rule a *mathematically* natural consequence, or a *physical additional axiom*?
2. **The consistency of infinite-dimensional unbounded operators** — the *unbounded* generalization of the Stone-von Neumann theorem is incomplete (e.g. position·momentum)
3. **The genuine equivalence Type II_1 ↔ BH** — CPW 2022 is a partial answer; whether *every BH is Type II_1* is incomplete
4. **A mathematical definition of QFT** — whether Wightman·Haag-Kastler axiomatic QFT applies to *4D Yang-Mills* (Millennium ⊆)
5. **Entanglement ↔ spacetime** — how far the exact matching von Neumann entropy ↔ entanglement wedge holds (PHYSICS 26 BPS·CPW)
6. **The completeness of the operator-algebra classification** — whether the Connes·Haagerup Type III classification subsumes *every QFT*
7. **An *algebra*-based formulation of quantum measurement** — what structure of modular flow measurement is
8. **The *mathematical* refinement of Bell inequality violation** — Tsirelson bound (Tsirelson 1980)·MIP\* = RE (Ji-Natarajan 2020)·the dimension of *infinite entanglement*
