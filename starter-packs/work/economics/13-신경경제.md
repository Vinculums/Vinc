## Mathematical structure

**Drift-Diffusion Model (DDM, Ratcliff 1978·Shadlen 2006)**:
$$dx = v \cdot dt + \sigma \cdot dW, \quad x(0) = 0, \quad \text{decide when } |x| \geq a$$
- $v$ = drift rate (evidence strength)·$\sigma$ = noise·$a$ = threshold
- predicts RT (reaction time) + accuracy simultaneously
- *economic decision = accumulation of value evidence* — Krajbich-Rangel (2011) eye-tracking verification

**Common Neural Currency** (Padoa-Schioppa 2006·2011):
$$\text{OFC neuron firing} = f(\text{subjective value})$$
- single OFC neurons in the monkey code the *juice vs. quantity trade-off* in a single currency
- human vmPFC BOLD signal = *neural verification of the utility function*

**Prospect Theory neural basis** (Tom-Fox-Trepel-Poldrack 2007 *Science*):
$$\lambda_{\text{neural}} = \frac{\partial \text{BOLD}_{loss}}{\partial \text{loss size}} \div \frac{\partial \text{BOLD}_{gain}}{\partial \text{gain size}}$$
- $\lambda_{\text{behavioral}} \approx \lambda_{\text{neural}}$ (individual loss aversion = striatum·vmPFC BOLD asymmetry)
- behavioral loss aversion ≈ neural loss aversion *correlation peak*

**Dopamine TD Error** (Schultz 1997·1998 *Science*):
$$\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$$
- VTA dopamine firing is *proportional to the TD error* — reinforcement learning + neural integration
- addiction = $\gamma$ ↓ (the neural basis of hyperbolic discount)

**Friston Free Energy**:
$$F = \mathbb{E}_q[\log q(z) - \log p(z, y)] \geq -\log p(y)$$
- the brain = a *variational inference engine*. All behavior = free-energy minimization
- yet *empirical verification* is limited

**Knoch-Fehr TMS** (2006 *Science*):
- right dlPFC TMS stimulation → punishment behavior ↓ (disabling insula reward)
- *causal intervention* — overcoming the correlational limit of fMRI
