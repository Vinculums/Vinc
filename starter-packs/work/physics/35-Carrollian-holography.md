## Mathematical structure

**Lévy-Leblond Carrollian group**:
$$x'^i = R^i_j x^j + b^i + v^i \tau$$
$$\tau' = \tau + a$$
- $R$ = rotation
- $\vec b$ = spatial translation
- $\vec v$ = Carrollian boost
- $a$ = time translation

**Carrollian boost**:
- Galilean: $x' = x + vt$, $t' = t$ (time absolute)
- Carrollian: $\tau' = \tau + v \cdot x$ (space absolute)
- *The time-space dual of the Galilean*

**Carrollian Lie algebra**:
$$[J_{ij}, J_{kl}] = \delta_{ik}J_{jl} - \cdots$$
$$[J_{ij}, P_k] = \delta_{jk}P_i - \delta_{ik}P_j$$
$$[J_{ij}, K_k] = \delta_{jk}K_i - \delta_{ik}K_j$$
$$[P_i, P_j] = 0$$
$$[P_i, K_j] = 0 \,\,\,\,\, (\text{Galilean: } i\delta_{ij}M)$$
$$[K_i, K_j] = 0$$
$$[H, P_i] = 0$$
$$[H, K_i] = -P_i$$
